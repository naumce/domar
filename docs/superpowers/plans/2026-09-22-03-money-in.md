# Domar Money In Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A manager records full or partial payments against invoices (or as owner credit), voids mistakes, imports a bank statement (MT940 or CSV) and has it matched to open invoices automatically or from a review queue, sees payments and balances across buildings, and owners' statements reconcile to the ledger.

**Architecture:** Pure parsing/matching in `@domar/domain` (MT940 + generic CSV parsers behind the country pack, a matching algorithm with `exact`/`likely` confidence, fund allocation by largest remainder). `@domar/db` adds `payments`, `bank_statements`, `statement_lines`, `tenants.timezone`, indexes. `apps/api` adds a payment service (postings on owner and fund accounts, invoice status recompute), statement import + review endpoints, tenant settings, dashboard stats and owner statements. `apps/web` adds payment recording on the invoice page, a payments page, a statements tab, dashboard numbers, contact statement and organization settings.

**Tech Stack:** unchanged (Node 24, pnpm 10, TS strict, Fastify 5 + zod, Drizzle + Postgres 16, Vue 3 + Vite + vue-i18n + Tailwind 4, Vitest, Playwright).

**Spec:** `docs/superpowers/specs/2026-09-21-domar-phase1-design.md` §4 (`payment`, `bank_statement`, `statement_line`), §7 (ledger rules), §8 (bank reconciliation), §15 item 3, §16. Previous plans: `2026-09-21-01-foundation.md`, `2026-09-21-02-billing-core.md` (patterns, ledger convention).

## Global Constraints

- Everything from the Foundation and Billing Core Global Constraints still applies (tenant filter on every statement, audit in-transaction, owner/accountant on writes, `bigint _minor` money, i18n parity, conventional commits, ESM `.js`, TS strict + exactOptionalPropertyTypes, run from repo root, Postgres on 54329).
- Ledger convention (binding): owner account: `charge` +, `payment` −; fund account: `opening`/`payment` +, `expense` −; `adjustment` signed. A payment writes, per fund it is allocated to, one owner `payment` posting (−alloc) and one fund `payment` posting (+alloc), `refType 'payment'`, `refId = payment.id`, `bookedAt = paidAt`. Voiding writes the exact opposite postings with `kind 'adjustment'`, `refType 'payment_void'`, `refId = payment.id`. Nothing is ever deleted from `postings`.
- Fund allocation of an invoice payment: proportional to the invoice's per-fund gross totals (`Σ ownerGrossMinor` of its lines by `fund`), split with `allocateLargestRemainder`; an unallocated payment (no invoice) goes to `regular`.
- Invoice status recompute after any payment change: `paidMinor = Σ completed payments`; for invoices in `published|partially_paid|paid`: `paid` when `paidMinor ≥ totalMinor`, `partially_paid` when `0 < paidMinor < totalMinor`, else `published`. Drafts/cancelled untouched. `outstandingMinor = max(0, totalMinor − paidMinor)`. (The invoice's `amountDueMinor` still includes the owner's previous balance; the owner's true position is the ledger balance.)
- Statement lines are credits (`amountMinor > 0`) to be matched; debits are stored for completeness but never suggested. Matching confidence: `exact` = an open invoice number appears in the normalized reference; `likely` = amount equals the outstanding of exactly one open invoice of the building AND the owner surname (Cyrillic or Latin) appears in reference/counterparty. `exact` auto-confirms on import when `autoConfirm` (default true); `likely` waits for review.
- Concurrency: payment creation claims the invoice row (`SELECT … FOR UPDATE` via `tx.execute` or a conditional `UPDATE invoices SET updated_at=now() WHERE id=… AND status IN ('published','partially_paid','paid') RETURNING`) before inserting; void claims the payment row with `UPDATE … WHERE status='completed' RETURNING`; statement line confirm claims the line with `UPDATE … WHERE match_status IN ('unmatched','suggested') RETURNING`.
- Money bounds: `amountMinor` 1..1e12 for payments; statements reject files > 2 MB and > 5 000 lines.

## Design addendum (decisions not in the spec)

1. `payments.invoice_id` nullable: an owner can pay "on account" (unallocated credit); the invoice list shows nothing for it, the owner statement does.
2. Overpayment is allowed and becomes owner credit in the ledger; the invoice status is `paid`.
3. `tenants.timezone` (IANA, default `Europe/Skopje`) is added now; invoice-number years and dashboard "this month" use it; `TZ` in `.env.example` stays as a fallback note.
4. `bank_statements.building_id` is required: statements are per building account. Re-importing the same file skips lines whose fingerprint `(building_id, sha256(bookedAt|amountMinor|reference|counterparty))` already exists and reports `skipped`.
5. `statement_lines.match_status`: `unmatched` → (`suggested`) → `matched` | `ignored`; `unmatch` voids the linked payment (reason `unmatched`) and returns the line to `unmatched`.
6. CSV format for the generic parser: header row with columns (case-insensitive, any order, `;` or `,` delimiter): `date` (`YYYY-MM-DD` or `DD.MM.YYYY`), `amount` (pack amount rules, negative = debit), `reference`, `counterparty` (optional). Bank-specific CSV/XLS parsers arrive when Phase 0 collects real files.
7. Owner statement (`GET /api/contacts/:id/statement?buildingId=`) lists owner postings chronologically with a running balance, each with `refType/refId` and a human label (invoice number or payment reference).
8. Dashboard stats are computed in the tenant's timezone month: `billedThisMonthMinor` (Σ totals of invoices published this month), `paidThisMonthMinor` (Σ completed payments with `paidAt` this month), `unpaidInvoices` (count `published|partially_paid`), `outstandingMinor` (Σ `outstandingMinor` of those).
9. Organization settings (`GET/PATCH /api/tenant`) expose name, company/VAT numbers, address, phone, email, bank name/account, timezone. Slug, country, currency are immutable here.

import type { ParsedStatementLine, StatementParseResult, StatementParser } from './types.js';

const TAG = /^:(\d{2}[A-Z]?):(.*)$/;
const TX = /^(\d{6})(\d{4})?(RC|RD|C|D)([A-Z])?(\d+(?:,\d*)?)(N|F)?([A-Z0-9]{3})?(.*)$/;

function yymmdd(s: string): string {
  const yy = Number(s.slice(0, 2));
  const year = yy < 70 ? 2000 + yy : 1900 + yy;
  return `${year}-${s.slice(2, 4)}-${s.slice(4, 6)}`;
}

/** Splits :86: text into purpose (?20-?29) and counterparty name (?32/?33) when the German ?-field convention is used. */
function details86(text: string): { purpose: string; counterparty: string } {
  if (!text.includes('?')) return { purpose: text.trim(), counterparty: '' };
  const fields = text.split('?').slice(1);
  let purpose = ''; let counterparty = '';
  for (const f of fields) {
    const code = f.slice(0, 2); const val = f.slice(2).trim();
    if (/^2\d$/.test(code)) purpose += (purpose ? ' ' : '') + val;
    else if (code === '32' || code === '33') counterparty += (counterparty ? ' ' : '') + val;
  }
  return { purpose, counterparty };
}

export const mt940Parser: StatementParser = {
  id: 'mt940',
  detect(text) { return /^:61:/m.test(text) || (/^:20:/m.test(text) && /^:25:/m.test(text)); },
  parse(text, amount) {
    const warnings: string[] = []; const lines: ParsedStatementLine[] = [];
    let accountNumber: string | null = null;
    // group into tag blocks (continuation lines belong to the previous tag)
    const blocks: { tag: string; text: string }[] = [];
    for (const rawLine of text.split(/\r?\n/)) {
      const m = TAG.exec(rawLine);
      if (m) blocks.push({ tag: m[1]!, text: m[2]! });
      else if (blocks.length && rawLine.trim() !== '' && rawLine.trim() !== '-') blocks[blocks.length - 1]!.text += '\n' + rawLine;
    }
    for (let i = 0; i < blocks.length; i++) {
      const b = blocks[i]!;
      if (b.tag === '25') accountNumber = b.text.trim().replace(/^[A-Z]{2}\d{2}/, (x) => x); // keep as-is; IBAN or account
      if (b.tag !== '61') continue;
      const first = b.text.split('\n')[0]!.trim();
      const m = TX.exec(first);
      if (!m) { warnings.push(`:61: line not understood: ${first.slice(0, 40)}`); continue; }
      const sign = m[3] === 'D' || m[3] === 'RD' ? -1 : 1;
      let amt: number;
      try { amt = amount(m[5]!.replace(/,$/, ',00')); } catch { warnings.push(`:61: amount not understood: ${m[5]}`); continue; }
      const rest = m[8] ?? '';
      const customerRef = rest.split('//')[0]!.trim();
      const next = blocks[i + 1];
      const info = next && next.tag === '86' ? details86(next.text.replace(/\n/g, ' ')) : { purpose: '', counterparty: '' };
      const referenceParts = [customerRef && customerRef !== 'NONREF' ? customerRef : '', info.purpose].filter(Boolean);
      lines.push({ bookedAt: yymmdd(m[1]!), amountMinor: sign * amt, reference: referenceParts.join(' ').trim(), counterparty: info.counterparty, raw: [first, next?.tag === '86' ? next.text : ''].filter(Boolean).join('\n') });
    }
    return { format: 'mt940', accountNumber: accountNumber ? accountNumber.trim() : null, lines, warnings };
  },
};

import type { ParsedStatementLine, StatementParseResult, StatementParser } from './types.js';

function splitCsvLine(line: string, delim: string): string[] {
  const out: string[] = []; let cur = ''; let q = false;
  for (let i = 0; i < line.length; i++) {
    const c = line[i]!;
    if (q) { if (c === '"' && line[i + 1] === '"') { cur += '"'; i++; } else if (c === '"') q = false; else cur += c; }
    else if (c === '"') q = true;
    else if (c === delim) { out.push(cur); cur = ''; }
    else cur += c;
  }
  out.push(cur);
  return out.map((s) => s.trim());
}

function header(text: string): { delim: string; cols: string[] } | null {
  const first = text.split(/\r?\n/).find((l) => l.trim() !== '');
  if (!first) return null;
  const delim = (first.split(';').length >= first.split(',').length) ? ';' : ',';
  const cols = splitCsvLine(first, delim).map((c) => c.toLowerCase());
  return cols.includes('date') && cols.includes('amount') ? { delim, cols } : null;
}

function isoDate(s: string): string | null {
  let m = /^(\d{4})-(\d{2})-(\d{2})$/.exec(s);
  if (m) return `${m[1]}-${m[2]}-${m[3]}`;
  m = /^(\d{2})\.(\d{2})\.(\d{4})$/.exec(s);
  if (m) return `${m[3]}-${m[2]}-${m[1]}`;
  return null;
}
const validDate = (iso: string) => { const d = new Date(`${iso}T00:00:00Z`); return !Number.isNaN(d.getTime()) && d.toISOString().startsWith(iso); };

export const csvParser: StatementParser = {
  id: 'csv',
  detect(text) { return header(text) !== null; },
  parse(text, amount) {
    const warnings: string[] = []; const lines: ParsedStatementLine[] = [];
    const h = header(text);
    if (!h) return { format: 'csv', accountNumber: null, lines, warnings: ['missing date/amount header'] };
    const rows = text.split(/\r?\n/).filter((l) => l.trim() !== '').slice(1);
    const idx = (name: string) => h.cols.indexOf(name);
    rows.forEach((row, n) => {
      const cells = splitCsvLine(row, h.delim);
      const iso = isoDate(cells[idx('date')] ?? '');
      if (!iso || !validDate(iso)) { warnings.push(`row ${n + 2}: bad date`); return; }
      let amt: number;
      try { amt = amount(cells[idx('amount')] ?? ''); } catch { warnings.push(`row ${n + 2}: bad amount`); return; }
      lines.push({ bookedAt: iso, amountMinor: amt, reference: idx('reference') >= 0 ? (cells[idx('reference')] ?? '') : '', counterparty: idx('counterparty') >= 0 ? (cells[idx('counterparty')] ?? '') : '', raw: row });
    });
    return { format: 'csv', accountNumber: null, lines, warnings };
  },
};

import type { ParsedStatementLine } from './types.js';

const CYR: Record<string, string> = { а: 'a', б: 'b', в: 'v', г: 'g', д: 'd', ѓ: 'gj', е: 'e', ж: 'zh', з: 'z', ѕ: 'dz', и: 'i', ј: 'j', к: 'k', л: 'l', љ: 'lj', м: 'm', н: 'n', њ: 'nj', о: 'o', п: 'p', р: 'r', с: 's', т: 't', ќ: 'kj', у: 'u', ф: 'f', х: 'h', ц: 'c', ч: 'ch', џ: 'dzh', ш: 'sh' };

export function transliterate(s: string): string {
  return [...s.toLowerCase()].map((c) => CYR[c] ?? c).join('');
}

/** Uppercase Latin, digits, '/' and '-' only. */
export function normalizeRef(s: string): string {
  return transliterate(s).toUpperCase().replace(/[^A-Z0-9/-]/g, '');
}

export interface MatchCandidate { invoiceId: string; number: string; contactLastName: string; outstandingMinor: number }
export type MatchResult = { invoiceId: string; confidence: 'exact' | 'likely' };

export function matchLine(line: ParsedStatementLine, candidates: MatchCandidate[]): MatchResult | null {
  if (line.amountMinor <= 0) return null;
  const text = normalizeRef(`${line.reference} ${line.counterparty}`);
  const exact = candidates.find((c) => c.number && text.includes(normalizeRef(c.number)));
  if (exact) return { invoiceId: exact.invoiceId, confidence: 'exact' };
  const byAmount = candidates.filter((c) => c.outstandingMinor === line.amountMinor);
  const withName = byAmount.filter((c) => { const n = normalizeRef(c.contactLastName); return n.length >= 3 && text.includes(n); });
  if (withName.length === 1) return { invoiceId: withName[0]!.invoiceId, confidence: 'likely' };
  if (byAmount.length === 1 && withName.length === 0) return null; // amount alone is not enough
  return null;
}

export function matchStatementLines(lines: ParsedStatementLine[], candidates: MatchCandidate[]) {
  const out: ({ index: number } & MatchResult)[] = [];
  lines.forEach((l, index) => { const m = matchLine(l, candidates); if (m) out.push({ index, ...m }); });
  return out;
}

import { type Db, schema } from '@domar/db';
import { allocateAcrossFunds } from '@domar/domain';
import { and, eq, inArray, sql } from 'drizzle-orm';
import { writeAudit } from '../../audit.js';
import { badRequest, conflict, notFound } from '../../errors.js';
import { addPostings, type NewPosting } from '../../ledger.js';
import type { TenantContext } from '../../tenant-context.js';

const INV = schema.invoices; const IL = schema.invoiceLines; const PAY = schema.payments; const P = schema.postings; const SL = schema.statementLines;
type Method = typeof PAY.$inferSelect.method;

export interface RecordPaymentInput { invoiceId?: string | null | undefined; buildingId?: string | undefined; contactId?: string | undefined; amountMinor: number; method: Method; paidAt: Date; reference?: string | null | undefined; note?: string | null | undefined; statementLineId?: string | null | undefined; createdBy?: string | null | undefined }

export async function recomputeInvoiceStatus(tx: Db, ctx: TenantContext, invoiceId: string) {
  const inv = await tx.query.invoices.findFirst({ where: and(eq(INV.tenantId, ctx.tenantId), eq(INV.id, invoiceId)) });
  if (!inv) throw notFound('Invoice');
  const [r] = await tx.select({ paid: sql<string>`coalesce(sum(${PAY.amountMinor}), 0)` }).from(PAY).where(and(eq(PAY.tenantId, ctx.tenantId), eq(PAY.invoiceId, invoiceId), eq(PAY.status, 'completed')));
  const paidMinor = Number(r?.paid ?? 0);
  const outstandingMinor = Math.max(0, inv.totalMinor - paidMinor);
  let status = inv.status;
  if (status === 'published' || status === 'partially_paid' || status === 'paid') {
    status = paidMinor >= inv.totalMinor ? 'paid' : paidMinor > 0 ? 'partially_paid' : 'published';
    if (status !== inv.status) await tx.update(INV).set({ status, updatedAt: new Date() }).where(and(eq(INV.tenantId, ctx.tenantId), eq(INV.id, invoiceId)));
  }
  return { id: invoiceId, status, paidMinor, outstandingMinor };
}

export async function recordPayment(tx: Db, ctx: TenantContext, input: RecordPaymentInput) {
  let buildingId: string; let contactId: string; let fundTotals: Partial<Record<'regular' | 'reserve', number>> = {};
  if (input.invoiceId) {
    const [inv] = await tx.update(INV).set({ updatedAt: new Date() })
      .where(and(eq(INV.tenantId, ctx.tenantId), eq(INV.id, input.invoiceId), inArray(INV.status, ['published', 'partially_paid', 'paid']))).returning();
    if (!inv) {
      const exists = await tx.query.invoices.findFirst({ where: and(eq(INV.tenantId, ctx.tenantId), eq(INV.id, input.invoiceId)), columns: { id: true } });
      if (!exists) throw notFound('Invoice');
      throw conflict('invoice_not_payable', 'Only published invoices can receive payments');
    }
    buildingId = inv.buildingId; contactId = inv.contactId;
    const totals = await tx.select({ fund: IL.fund, total: sql<string>`sum(${IL.ownerGrossMinor})` }).from(IL).where(and(eq(IL.tenantId, ctx.tenantId), eq(IL.invoiceId, inv.id))).groupBy(IL.fund);
    for (const row of totals) fundTotals[row.fund] = Number(row.total);
  } else {
    if (!input.buildingId || !input.contactId) throw badRequest('validation', 'buildingId and contactId are required without an invoice');
    const c = await tx.query.contacts.findFirst({ where: and(eq(schema.contacts.tenantId, ctx.tenantId), eq(schema.contacts.id, input.contactId)), columns: { id: true } });
    if (!c) throw badRequest('invalid_reference', 'contactId does not belong to this organization');
    const b = await tx.query.buildings.findFirst({ where: and(eq(schema.buildings.tenantId, ctx.tenantId), eq(schema.buildings.id, input.buildingId)), columns: { id: true } });
    if (!b) throw notFound('Building');
    buildingId = input.buildingId; contactId = input.contactId; fundTotals = { regular: 1 };
  }
  const [payment] = await tx.insert(PAY).values({
    tenantId: ctx.tenantId, buildingId, invoiceId: input.invoiceId ?? null, contactId, amountMinor: input.amountMinor, method: input.method, paidAt: input.paidAt,
    reference: input.reference ?? null, note: input.note ?? null, statementLineId: input.statementLineId ?? null, createdBy: input.createdBy ?? ctx.userId,
  }).returning();
  const alloc = allocateAcrossFunds(input.amountMinor, fundTotals);
  const postings: NewPosting[] = [];
  for (const fund of ['regular', 'reserve'] as const) {
    const amt = alloc[fund];
    if (amt <= 0) continue;
    postings.push({ account: 'owner', contactId, buildingId, fund, kind: 'payment', amountMinor: -amt, refType: 'payment', refId: payment!.id, bookedAt: input.paidAt });
    postings.push({ account: 'fund', buildingId, fund, kind: 'payment', amountMinor: amt, refType: 'payment', refId: payment!.id, bookedAt: input.paidAt });
  }
  await addPostings(tx, ctx, postings);
  const invoice = input.invoiceId ? await recomputeInvoiceStatus(tx, ctx, input.invoiceId) : null;
  await writeAudit(tx, ctx, { action: 'payment.record', entityType: 'payment', entityId: payment!.id, after: payment });
  return { payment: payment!, invoice };
}

export async function voidPayment(tx: Db, ctx: TenantContext, id: string, reason: string) {
  const [payment] = await tx.update(PAY).set({ status: 'voided', voidReason: reason, voidedAt: new Date(), updatedAt: new Date() })
    .where(and(eq(PAY.tenantId, ctx.tenantId), eq(PAY.id, id), eq(PAY.status, 'completed'))).returning();
  if (!payment) {
    const exists = await tx.query.payments.findFirst({ where: and(eq(PAY.tenantId, ctx.tenantId), eq(PAY.id, id)), columns: { id: true } });
    if (!exists) throw notFound('Payment');
    throw conflict('already_voided', 'Payment is already voided');
  }
  const originals = await tx.select().from(P).where(and(eq(P.tenantId, ctx.tenantId), eq(P.refType, 'payment'), eq(P.refId, id)));
  await addPostings(tx, ctx, originals.map((o): NewPosting => o.account === 'owner'
    ? { account: 'owner', contactId: o.contactId!, buildingId: o.buildingId, fund: o.fund, kind: 'adjustment', amountMinor: -o.amountMinor, refType: 'payment_void', refId: id, period: o.period }
    : { account: 'fund', buildingId: o.buildingId, fund: o.fund, kind: 'adjustment', amountMinor: -o.amountMinor, refType: 'payment_void', refId: id, period: o.period }));
  if (payment.statementLineId) {
    await tx.update(SL).set({ matchStatus: 'unmatched', paymentId: null, confidence: null }).where(and(eq(SL.tenantId, ctx.tenantId), eq(SL.id, payment.statementLineId)));
  }
  const invoice = payment.invoiceId ? await recomputeInvoiceStatus(tx, ctx, payment.invoiceId) : null;
  await writeAudit(tx, ctx, { action: 'payment.void', entityType: 'payment', entityId: id, after: payment });
  return { payment, invoice };
}

import { and, asc, count, desc, eq, gte, ilike, lt, or, sql } from 'drizzle-orm';
import { notFound } from '../../errors.js';
import type { TenantContext } from '../../tenant-context.js';

const PAY = schema.payments; const C = schema.contacts; const INV = schema.invoices; const B = schema.buildings;
const shape = { p: PAY, contact: { id: C.id, firstName: C.firstName, lastName: C.lastName }, invoice: { id: INV.id, number: INV.number }, building: { id: B.id, name: B.name } };
const joined = (db: Db) => db.select(shape).from(PAY).innerJoin(C, eq(C.id, PAY.contactId)).leftJoin(INV, eq(INV.id, PAY.invoiceId)).innerJoin(B, eq(B.id, PAY.buildingId));
const toOut = (r: { p: typeof PAY.$inferSelect; contact: { id: string; firstName: string; lastName: string }; invoice: { id: string | null; number: string | null } | null; building: { id: string; name: string } }) =>
  ({ ...r.p, contact: r.contact, invoice: r.invoice?.id ? { id: r.invoice.id, number: r.invoice.number } : null, building: r.building });

export interface PaymentListQuery { buildingId?: string | undefined; contactId?: string | undefined; invoiceId?: string | undefined; method?: string | undefined; status?: string | undefined; from?: string | undefined; to?: string | undefined; search?: string | undefined; page: number; pageSize: number }

export async function listPayments(db: Db, ctx: TenantContext, q: PaymentListQuery) {
  const conds = [eq(PAY.tenantId, ctx.tenantId)];
  if (q.buildingId) conds.push(eq(PAY.buildingId, q.buildingId));
  if (q.contactId) conds.push(eq(PAY.contactId, q.contactId));
  if (q.invoiceId) conds.push(eq(PAY.invoiceId, q.invoiceId));
  if (q.method) conds.push(eq(PAY.method, q.method as typeof PAY.$inferSelect.method));
  if (q.status) conds.push(eq(PAY.status, q.status as typeof PAY.$inferSelect.status));
  if (q.from) conds.push(gte(PAY.paidAt, new Date(q.from)));
  if (q.to) conds.push(lt(PAY.paidAt, new Date(q.to)));
  if (q.search) { const term = `%${q.search.replace(/[\\%_]/g, (m) => '\\' + m)}%`; conds.push(or(ilike(PAY.reference, term), ilike(INV.number, term))!); }
  const where = and(...conds);
  const [rows, totalRows, summaryRows, byMethod] = await Promise.all([
    joined(db).where(where).orderBy(desc(PAY.paidAt), desc(PAY.createdAt), asc(PAY.id)).limit(q.pageSize).offset((q.page - 1) * q.pageSize),
    db.select({ total: count() }).from(PAY).leftJoin(INV, eq(INV.id, PAY.invoiceId)).where(where),
    db.select({ status: PAY.status, n: count(), total: sql<string>`coalesce(sum(${PAY.amountMinor}), 0)` }).from(PAY).leftJoin(INV, eq(INV.id, PAY.invoiceId)).where(where).groupBy(PAY.status),
    db.select({ method: PAY.method, total: sql<string>`coalesce(sum(${PAY.amountMinor}), 0)` }).from(PAY).leftJoin(INV, eq(INV.id, PAY.invoiceId)).where(and(where, eq(PAY.status, 'completed'))).groupBy(PAY.method),
  ]);
  const completed = summaryRows.find((s) => s.status === 'completed'); const voided = summaryRows.find((s) => s.status === 'voided');
  return {
    rows: rows.map(toOut), total: Number(totalRows[0]?.total ?? 0),
    summary: { totalMinor: Number(completed?.total ?? 0), completedCount: Number(completed?.n ?? 0), voidedCount: Number(voided?.n ?? 0), byMethod: byMethod.map((m) => ({ method: m.method, totalMinor: Number(m.total) })) },
  };
}

export async function getPayment(db: Db, ctx: TenantContext, id: string) {
  const [r] = await joined(db).where(and(eq(PAY.tenantId, ctx.tenantId), eq(PAY.id, id))).limit(1);
  if (!r) throw notFound('Payment');
  return toOut(r);
}

```ts
import { createHash } from 'node:crypto';
import { type Db, schema } from '@domar/db';
import { detectStatementParser, getCountryPack, matchStatementLines, type CountryCode, type MatchCandidate } from '@domar/domain';
import { and, asc, desc, eq, inArray, sql } from 'drizzle-orm';
import { writeAudit } from '../../audit.js';
import { badRequest, conflict, notFound } from '../../errors.js';
import type { TenantContext } from '../../tenant-context.js';
import { getBuilding } from '../buildings/repo.js';
import { recordPayment, voidPayment } from '../payments/service.js';

const BS = schema.bankStatements; const SL = schema.statementLines; const INV = schema.invoices; const C = schema.contacts; const PAY = schema.payments;
const MAX_BYTES = 2 * 1024 * 1024; const MAX_LINES = 5000;
const fingerprint = (l: { bookedAt: string; amountMinor: number; reference: string; counterparty: string }) => createHash('sha256').update(`${l.bookedAt}|${l.amountMinor}|${l.reference}|${l.counterparty}`).digest('hex');
const noon = (iso: string) => new Date(`${iso}T12:00:00.000Z`);

async function openInvoices(tx: Db, ctx: TenantContext, buildingId: string): Promise<(MatchCandidate & { contactId: string })[]> {
  const rows = await tx.select({ id: INV.id, number: INV.number, totalMinor: INV.totalMinor, contactId: INV.contactId, lastName: C.lastName,
    paid: sql<string>`(select coalesce(sum(p.amount_minor),0) from payments p where p.invoice_id = "invoices"."id" and p.status = 'completed')` })
    .from(INV).innerJoin(C, eq(C.id, INV.contactId)).where(and(eq(INV.tenantId, ctx.tenantId), eq(INV.buildingId, buildingId), inArray(INV.status, ['published', 'partially_paid'])));
  return rows.map((r) => ({ invoiceId: r.id, number: r.number ?? '', contactLastName: r.lastName, outstandingMinor: Math.max(0, r.totalMinor - Number(r.paid)), contactId: r.contactId }));
}

export async function importStatement(db: Db, ctx: TenantContext, buildingId: string, input: { filename: string; content: string; autoConfirm?: boolean | undefined }) {
  if (Buffer.byteLength(input.content, 'utf8') > MAX_BYTES) throw badRequest('too_large', 'Statement file exceeds 2 MB');
  return db.transaction(async (tx) => {
    await getBuilding(tx, ctx, buildingId);
    const tenant = (await tx.query.tenants.findFirst({ where: eq(schema.tenants.id, ctx.tenantId) }))!;
    const pack = getCountryPack(tenant.countryCode as CountryCode);
    const parser = detectStatementParser(input.content, pack);
    if (!parser) throw badRequest('unknown_format', 'Statement format not recognised (MT940 or CSV with date/amount columns)');
    const parsed = parser.parse(input.content, pack.parseAmountToMinor);
    if (parsed.lines.length > MAX_LINES) throw badRequest('too_many_lines', `Statement has more than ${MAX_LINES} lines`);
    const [st] = await tx.insert(BS).values({ tenantId: ctx.tenantId, buildingId, filename: input.filename, format: parsed.format, accountNumber: parsed.accountNumber, createdBy: ctx.userId }).returning();
    const existing = new Set((await tx.select({ fp: SL.fingerprint }).from(SL).where(and(eq(SL.tenantId, ctx.tenantId), eq(SL.buildingId, buildingId)))).map((r) => r.fp));
    const fresh = parsed.lines.filter((l) => !existing.has(fingerprint(l)));
    const skipped = parsed.lines.length - fresh.length;
    const inserted = fresh.length ? await tx.insert(SL).values(fresh.map((l, i) => ({ tenantId: ctx.tenantId, statementId: st!.id, buildingId, lineNo: i + 1, bookedAt: noon(l.bookedAt), amountMinor: l.amountMinor, counterparty: l.counterparty || null, reference: l.reference || null, raw: l.raw, fingerprint: fingerprint(l) }))).returning() : [];
    const candidates = await openInvoices(tx, ctx, buildingId);
    const matches = matchStatementLines(fresh, candidates);
    let matched = 0;
    for (const m of matches) {
      const line = inserted[m.index]!;
      await tx.update(SL).set({ matchStatus: 'suggested', confidence: m.confidence, suggestedInvoiceId: m.invoiceId }).where(eq(SL.id, line.id));
      if (m.confidence === 'exact' && input.autoConfirm !== false) {
        const { payment } = await recordPayment(tx, ctx, { invoiceId: m.invoiceId, amountMinor: line.amountMinor, method: 'bank_transfer', paidAt: line.bookedAt, reference: line.reference, statementLineId: line.id });
        await tx.update(SL).set({ matchStatus: 'matched', paymentId: payment.id }).where(eq(SL.id, line.id));
        matched++;
      }
    }
    await tx.update(BS).set({ lineCount: inserted.length, matchedCount: matched, skippedCount: skipped }).where(eq(BS.id, st!.id));
    await writeAudit(tx, ctx, { action: 'statement.import', entityType: 'bank_statement', entityId: st!.id, after: { filename: input.filename, lines: inserted.length, matched, skipped, warnings: parsed.warnings } });
    return { ...(await getStatement(tx, ctx, st!.id)), warnings: parsed.warnings };
  });
}
```
`getStatement` joins lines with `suggestedInvoice` (invoice + contact lastName + outstanding via the same subquery) and `payment` (id, amountMinor, status); `listStatements` orders by `importedAt desc`; `confirmLine`/`ignoreLine`/`unmatchLine` as specified (all tenant-scoped, claims via conditional UPDATE, audit). `confirmLine` validates the invoice is open and `buildingId` matches the line's building (`400 invalid_reference`), and `amountMinor > 0` (`400 not_a_credit`). `unmatchLine`: if the line is `matched` with a payment → `voidPayment(tx, ctx, paymentId, 'unmatched')` (which resets the line) and return the refreshed line; if `ignored` → set `unmatched`; else `409 line_not_matched`.

Routes: three plugins — `buildingStatementRoutes` (`GET /`, `POST /` under `/buildings/:buildingId/statements`), `statementRoutes` (`GET /:id` under `/statements`), `statementLineRoutes` (`POST /:id/confirm|ignore|unmatch` under `/statement-lines`). Register in `app.ts`.
