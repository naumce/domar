# Domar Pilot Ready Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One design-partner management company can run a real billing month on domar: a migrating building's existing owner debts and credits are entered as opening balances, units and owners arrive from a CSV export instead of being typed one by one, the company owner creates staff logins without an email server, and the whole thing runs on one server behind HTTPS with migrations on start and a nightly database dump.

**Architecture:** `@domar/db` adds `users.is_active`. `@domar/domain` adds a pure CSV parser for the unit/owner template (`import/units.ts`) reusing the statement CSV splitter and the `mk` pack's amount parser. `apps/api` adds three resources — `opening-balances` (owner `opening` postings per row, per-fund owner balances), `users` (staff CRUD with server-generated temporary passwords, `isActive` gating in the auth plugin, self-service change-password) and `import` (dry-run preview + one-transaction commit that reuses the units repo's insert and the opening-balances repo) — plus `@fastify/static` SPA serving behind `SERVE_WEB`. `apps/web` adds two building tabs (Opening balances, Import) and a Users section plus a change-password form on the settings page. The root gains a multi-stage `Dockerfile` on the Playwright image, `docker-compose.prod.yml` with Caddy, a backup script and `docs/DEPLOY.md`.

**Tech Stack:** unchanged (Node 24, pnpm 10, TS strict, Fastify 5 + zod, Drizzle + Postgres 16, Vue 3 + Vite + vue-i18n + Tailwind 4, Vitest, Playwright 1.63.0). New runtime dependencies: `@fastify/static` (API), `tsx` promoted from devDependency to dependency of `@domar/api` (it is the production runtime).

**Spec:** `docs/superpowers/specs/2026-09-21-domar-phase1-design.md` §17 (the four deliverables of this sub-plan), §7 (ledger rules), §10 (auth and tenancy), §11 (API shape), §12 (web), §16 (global constraints). Previous plans: `2026-09-21-01-foundation.md`, `2026-09-21-02-billing-core.md`, `2026-09-22-03-money-in.md` (patterns, ledger convention, claim-first transitions).

## Global Constraints

From spec §16, verbatim:

- Node `>=24`, pnpm `>=10`, TypeScript strict, ESM only.
- Postgres 16; schema must run unchanged on Supabase Postgres (no superuser-only extensions; `pgcrypto`/`uuid-ossp` allowed).
- Every tenant-scoped table has `tenant_id uuid not null` and an index starting with it.
- Money columns: `bigint`, suffix `_minor`. Never `float`.
- All user-facing strings in the web app go through i18n; Macedonian first, English second.
- No secrets in the repo; `.env.example` documents every variable.
- Commit after every green test cycle; conventional commit messages.

Project conventions that are equally binding here:

- **Money is integer minor units** everywhere (`number` in TS, `bigint` in Postgres). Amounts on the wire end in `Minor`. Opening balances are signed: positive = the owner owes the building.
- **Tenant filter on every statement**, including correlated subqueries and every `and(...)` in a repo. Nothing is fetched by id alone; the id is always paired with `eq(table.tenantId, ctx.tenantId)`.
- **An audit row is written inside the same transaction as every mutation** (`writeAudit(tx, ctx, …)`), never after it and never outside it. Audit payloads never contain a password hash.
- **Role gating:** writes use `preHandler: requireRole(...WRITE_ROLES)` (`owner`, `accountant`); the endpoints §17 marks owner-only (`POST /users`, `PATCH /users/:id`, `POST /users/:id/reset-password`) use `preHandler: requireRole('owner')`. Reads only need `app.requireAuth`.
- **Error envelope:** `{ error: { code, message, details? } }` produced by `AppError`/`notFound`/`badRequest`/`conflict` and the handler in `app.ts`. New codes in this plan: `period_published`, `last_owner`, `email_taken`, `label_conflict`.
- **Claim-first `UPDATE … RETURNING` for state transitions** (the existing `claimPeriod`, `publishPeriod` and payment/statement-line claims). New code in this plan performs no state transition on an existing row except `users` updates, which are single-row updates predicated on tenant + id inside a transaction.
- **TS strict with `exactOptionalPropertyTypes`**: never pass an explicit `undefined` into an object typed with an optional property unless the property type includes `| undefined`; use `stripUndefined()` before drizzle `.set()`/`.values()` spreads.
- **ESM `.js` import specifiers** in every TS import of a local file (`./repo.js`, `../../ledger.js`), `import type` for type-only imports (`@typescript-eslint/consistent-type-imports` is an error).
- **i18n mk/en parity**: `apps/web/test/LoginPage.test.ts` asserts `flatKeys(messages.en).sort()` equals `flatKeys(messages.mk).sort()`. Every key added in this plan must be added to both files, Macedonian first.
- **`data-test` hooks** on every element an e2e test touches (`testIdAttribute: 'data-test'` in `e2e/playwright.config.ts`).
- Run everything from the repo root. Postgres for tests is the docker-compose service on port 54329 (`pnpm db:up`).
- **Conventional commits**, each ending with the trailer:

## Design addendum (decisions not spelled out in the spec)

1. **Opening balances are one posting per row**, never aggregated: `account 'owner'`, `kind 'opening'`, `refType 'opening_balance'`, `refId null`, `fund` from the row, `bookedAt` from the row or `now()`. The optional `note` has no column on `postings`, so it is kept in the audit payload only — the same thing `reserveFund.opening_balance` already does.
2. **`409 period_published`** is raised when the building has any `billing_periods` row with `status = 'published'`, unless the body carries `force: true`. The audit row records `force` and `afterPublishedPeriod`, so a forced correction is traceable.
3. **`GET /buildings/:id/opening-balances` lists unit owners**, i.e. the distinct contacts referenced by `units.owner_contact_id` in that building, each with `regularMinor`, `reserveMinor`, `balanceMinor` (their sum) and `openingMinor` (the part that came from `opening` postings, so the UI can tell "already entered" from "billed"). A contact with owner postings but no unit any more is not listed; the contact statement (`GET /contacts/:id/statement`) still shows them.
4. **Writes to opening balances use `WRITE_ROLES`**, not owner-only: §17 says "owner" there in the sense of *unit owner*, and an accountant migrating a building must be able to enter them. Only §17 item 2 (`users`) is owner-role-only.
5. **`PATCH /users/:id` is owner-only** like `POST /users` and `POST /users/:id/reset-password`: it changes role and `isActive`. `GET /users` needs only a session — staff names inside one tenant are not sensitive and the web shell shows them.
6. **Temporary passwords** are 16 characters drawn with rejection sampling from a 57-character unambiguous alphabet (no `I`, `O`, `l`, `0`, `1`). They are returned exactly once, in the `POST /users` and `POST /users/:id/reset-password` responses, and are never stored in plaintext or in an audit payload.
7. **Changing your own password keeps your current session and deletes your other sessions.** Deactivating a user or resetting their password deletes *all* of that user's sessions; the auth plugin additionally refuses a session whose user is inactive, so a cookie minted a millisecond before deactivation is dead too.
8. **The CSV import's `dryRun` and `mode` are body fields, not query parameters** (§17 writes `?dryRun=true`; the body keeps one schema for one endpoint and survives a 3 MB payload). The endpoint answers `200` for both a preview and a commit.
9. **Parse errors do not block a commit.** Rows that fail validation are reported in `errors[]` and skipped; the valid rows are imported. The web forces a dry-run preview before the commit button becomes usable, which is where the operator sees the errors.
10. **`counts` always describes what a commit *in the requested mode* would create**: `units` counts rows whose label does not already exist in the building, `conflicts` counts the labels that do. With `mode: 'fail'` a commit with `conflicts > 0` is refused with `409 label_conflict` and `details.labels`.
11. **Owner matching in the import**: by `lower(email)` within the tenant when the row has an email, else by exact `firstName` + `lastName` within the tenant, else the contact is created. Rows repeating the same owner in one file resolve to one contact.
12. **The production image runs the API with `tsx`, not with `node` on compiled output.** `@domar/db` and `@domar/domain` publish TypeScript sources (`"exports": "./src/index.ts"`), so a `tsc`-emitted `apps/api/dist` would still `import '@domar/db'` and Node would be handed a `.ts` file; compiling those packages instead would mean changing their `exports` and breaking the dev/test setup that every other package relies on. The image therefore keeps the pnpm workspace layout (no `pnpm deploy`, which would copy the workspace packages *into* `node_modules` and make things worse), and `pnpm --filter @domar/api start` runs `tsx src/index.ts` exactly as `dev` does today. `apps/api`'s new `build` script (`tsc -p tsconfig.build.json`) is the production compile gate — `src` only, no test files — and runs in the image build so a type error fails the image.
13. **Cookie `secure` keeps following `isProduction`** (already the case in `auth/routes.ts`); no `COOKIE_SECURE` variable is introduced.

/** Owner balances in a building split by fund, with the share that came from `opening` postings. */
export async function ownerBalancesByFund(
  db: Db,
  ctx: TenantContext,
  buildingId: string,
): Promise<Record<string, { regularMinor: number; reserveMinor: number; openingMinor: number }>> {
  const rows = await db
    .select({
      contactId: P.contactId,
      fund: P.fund,
      total: sum,
      opening: sql<string>`coalesce(sum(case when ${P.kind} = 'opening' then ${P.amountMinor} else 0 end), 0)`,
    })
    .from(P)
    .where(and(eq(P.tenantId, ctx.tenantId), eq(P.buildingId, buildingId), eq(P.account, 'owner')))
    .groupBy(P.contactId, P.fund);
  const out: Record<string, { regularMinor: number; reserveMinor: number; openingMinor: number }> = {};
  for (const r of rows) {
    if (!r.contactId) continue;
    const e = (out[r.contactId] ??= { regularMinor: 0, reserveMinor: 0, openingMinor: 0 });
    if (r.fund === 'reserve') e.reserveMinor += Number(r.total);
    else e.regularMinor += Number(r.total);
    e.openingMinor += Number(r.opening);
  }
  return out;
}

`apps/api/src/resources/opening-balances/repo.ts`:

```ts
import { type Db, schema } from '@domar/db';
import { and, asc, eq } from 'drizzle-orm';
import { writeAudit } from '../../audit.js';
import { badRequest, conflict } from '../../errors.js';
import { addPosting, ownerBalancesByFund } from '../../ledger.js';
import type { TenantContext } from '../../tenant-context.js';
import { getBuilding } from '../buildings/repo.js';
import type { OpeningBalanceCreate, OpeningBalanceRow } from './schema.js';

const BP = schema.billingPeriods; const C = schema.contacts; const U = schema.units;

type InsertedOpening = { id: string; contactId: string; fund: 'regular' | 'reserve'; amountMinor: number; bookedAt: Date; note: string | null };

/** True when the building already has a published period, i.e. opening balances would rewrite history. */
export async function hasPublishedPeriod(db: Db, ctx: TenantContext, buildingId: string): Promise<boolean> {
  const row = await db.query.billingPeriods.findFirst({
    where: and(eq(BP.tenantId, ctx.tenantId), eq(BP.buildingId, buildingId), eq(BP.status, 'published')),
    columns: { id: true },
  });
  return row !== undefined;
}

/**
 * Books one owner `opening` posting per row. Runs inside the caller's transaction: no audit row,
 * no published-period guard, no building lookup — `addOpeningBalances` and the CSV import do those.
 */
export async function insertOpeningBalances(tx: Db, ctx: TenantContext, buildingId: string, rows: OpeningBalanceRow[]): Promise<InsertedOpening[]> {
  for (const contactId of [...new Set(rows.map((r) => r.contactId))]) {
    const c = await tx.query.contacts.findFirst({ where: and(eq(C.tenantId, ctx.tenantId), eq(C.id, contactId)), columns: { id: true } });
    if (!c) throw badRequest('invalid_reference', `contactId ${contactId} does not belong to this organization`);
  }
  const out: InsertedOpening[] = [];
  for (const r of rows) {
    const posting = await addPosting(tx, ctx, {
      buildingId, account: 'owner', contactId: r.contactId, fund: r.fund, kind: 'opening',
      amountMinor: r.amountMinor, refType: 'opening_balance',
      bookedAt: r.bookedAt ? new Date(r.bookedAt) : undefined,
    });
    out.push({ id: posting.id, contactId: r.contactId, fund: r.fund, amountMinor: r.amountMinor, bookedAt: posting.bookedAt, note: r.note ?? null });
  }
  return out;
}

export async function addOpeningBalances(db: Db, ctx: TenantContext, buildingId: string, input: OpeningBalanceCreate) {
  return db.transaction(async (tx) => {
    await getBuilding(tx, ctx, buildingId);
    const published = await hasPublishedPeriod(tx, ctx, buildingId);
    if (published && !input.force) throw conflict('period_published', 'This building already has a published period; resend with force: true to book anyway');
    const postings = await insertOpeningBalances(tx, ctx, buildingId, input.rows);
    await writeAudit(tx, ctx, {
      action: 'opening_balance.create', entityType: 'building', entityId: buildingId,
      after: { count: postings.length, totalMinor: postings.reduce((a, p) => a + p.amountMinor, 0), force: input.force, afterPublishedPeriod: published, rows: postings },
    });
    return { created: postings.length, postings };
  });
}

/** No I, O, l, 0 or 1: a temporary password gets read off a screen and typed by hand. */
const TEMP_ALPHABET = 'ABCDEFGHJKLMNPQRSTUVWXYZabcdefghijkmnopqrstuvwxyz23456789';
const TEMP_LENGTH = 16;

/** 16 characters drawn uniformly from TEMP_ALPHABET (rejection sampling, so no modulo bias). */
export function generateTemporaryPassword(): string {
  const n = TEMP_ALPHABET.length;
  const limit = 256 - (256 % n);
  let out = '';
  while (out.length < TEMP_LENGTH) {
    for (const b of randomBytes(TEMP_LENGTH)) {
      if (b >= limit) continue;
      out += TEMP_ALPHABET[b % n];
      if (out.length === TEMP_LENGTH) break;
    }
  }
  return out;
}

async function getUser(db: Db, ctx: TenantContext, id: string): Promise<Row> {
  const row = await db.query.users.findFirst({ where: and(eq(U.tenantId, ctx.tenantId), eq(U.id, id)) });
  if (!row) throw notFound('User');
  return row;
}

/** Active owners of the tenant other than `exceptId`. */
async function otherActiveOwners(db: Db, ctx: TenantContext, exceptId: string): Promise<number> {
  const [r] = await db.select({ total: count() }).from(U)
    .where(and(eq(U.tenantId, ctx.tenantId), eq(U.role, 'owner'), eq(U.isActive, true), ne(U.id, exceptId)));
  return Number(r?.total ?? 0);
}

export async function createUser(db: Db, ctx: TenantContext, input: UserCreate) {
  const temporaryPassword = generateTemporaryPassword();
  const passwordHash = await hashPassword(temporaryPassword);
  const email = input.email.toLowerCase();
  return db.transaction(async (tx) => {
    let row: Row | undefined;
    try {
      [row] = await tx.insert(U).values({
        tenantId: ctx.tenantId, email, passwordHash, firstName: input.firstName, lastName: input.lastName, role: input.role,
      }).returning();
    } catch (err) {
      if (isUniqueViolation(err)) throw conflict('email_taken', 'A user with that email already exists in this organization');
      throw err;
    }
    if (!row) throw new AppError(500, 'internal', 'user insert failed');
    await writeAudit(tx, ctx, { action: 'user.create', entityType: 'user', entityId: row.id, after: publicUser(row) });
    return { user: publicUser(row), temporaryPassword };
  });
}

export async function updateUser(db: Db, ctx: TenantContext, id: string, patch: UserPatch) {
  return db.transaction(async (tx) => {
    const before = await getUser(tx, ctx, id);
    const losesTheLastOwner = before.role === 'owner' && before.isActive
      && ((patch.role !== undefined && patch.role !== 'owner') || patch.isActive === false);
    if (losesTheLastOwner && (await otherActiveOwners(tx, ctx, id)) === 0) {
      throw conflict('last_owner', 'The last active owner cannot be demoted or deactivated');
    }
    const [row] = await tx.update(U).set({ ...stripUndefined(patch), updatedAt: new Date() })
      .where(and(eq(U.tenantId, ctx.tenantId), eq(U.id, id))).returning();
    if (!row) throw notFound('User');
    if (patch.isActive === false) await deleteSessionsForUser(tx, id);
    await writeAudit(tx, ctx, { action: 'user.update', entityType: 'user', entityId: id, before: publicUser(before), after: publicUser(row) });
    return publicUser(row);
  });
}

export async function resetUserPassword(db: Db, ctx: TenantContext, id: string) {
  const temporaryPassword = generateTemporaryPassword();
  const passwordHash = await hashPassword(temporaryPassword);
  return db.transaction(async (tx) => {
    const before = await getUser(tx, ctx, id);
    const [row] = await tx.update(U).set({ passwordHash, updatedAt: new Date() })
      .where(and(eq(U.tenantId, ctx.tenantId), eq(U.id, id))).returning();
    if (!row) throw notFound('User');
    await deleteSessionsForUser(tx, id);
    await writeAudit(tx, ctx, { action: 'user.reset_password', entityType: 'user', entityId: id, after: { email: before.email } });
    return { user: publicUser(row), temporaryPassword };
  });
}

/** Self-service. `keepToken` is the caller's session token: every other session of theirs is dropped. */
export async function changeOwnPassword(db: Db, ctx: TenantContext, currentPassword: string, newPassword: string, keepToken: string): Promise<void> {
  const user = await getUser(db, ctx, ctx.userId);
  if (!(await verifyPassword(currentPassword, user.passwordHash))) throw new AppError(401, 'invalid_credentials', 'The current password is wrong');
  const passwordHash = await hashPassword(newPassword);
  await db.transaction(async (tx) => {
    await tx.update(U).set({ passwordHash, updatedAt: new Date() }).where(and(eq(U.tenantId, ctx.tenantId), eq(U.id, ctx.userId)));
    await deleteOtherSessionsForUser(tx, ctx.userId, keepToken);
    await writeAudit(tx, ctx, { action: 'user.change_password', entityType: 'user', entityId: ctx.userId });
  });
}

Accepted kinds: `apartment|стан`, `commercial|деловен|деловен простор`, `parking|паркинг`, `storage|подрум|остава` (`Остава` is the label the web UI itself shows), `other|друго`. `label` and `kind` columns are required; owner columns are optional and a unit with no owner is valid. Delimiter is `;` unless the header line contains more `,` than `;`; a leading BOM is stripped; `\r\n` and `\n` both work; quoted fields (including a quoted delimiter) are handled by the shared `splitCsvLine`. `areaM2`/`ownershipShare` accept a decimal comma or point; `openingBalance` goes through `mkPack.parseAmountToMinor`, which accepts `1.200,00`, `1200.00`, `-450,50`.

import type { UnitKind } from '../calculation/types.js';
import { mkPack } from '../country/mk.js';
import { splitCsvLine } from '../statements/csv.js';

export interface UnitImportRow {
  line: number;
  label: string;
  floor: string | null;
  kind: UnitKind;
  areaM2: number | null;
  ownershipShare: number | null;
  ownerFirstName: string | null;
  ownerLastName: string | null;
  ownerEmail: string | null;
  ownerPhone: string | null;
  openingBalanceMinor: number;
}
export interface UnitImportError { line: number; message: string }
export interface UnitImportResult { rows: UnitImportRow[]; errors: UnitImportError[] }

type Field =
  | 'label' | 'floor' | 'kind' | 'areaM2' | 'ownershipShare'
  | 'ownerFirstName' | 'ownerLastName' | 'ownerEmail' | 'ownerPhone' | 'openingBalance';

const HEADERS: Record<string, Field> = {
  label: 'label', 'број': 'label',
  floor: 'floor', 'кат': 'floor',
  kind: 'kind', 'тип': 'kind',
  aream2: 'areaM2', 'површина': 'areaM2',
  ownershipshare: 'ownershipShare', 'удел': 'ownershipShare',
  ownerfirstname: 'ownerFirstName', 'име': 'ownerFirstName',
  ownerlastname: 'ownerLastName', 'презиме': 'ownerLastName',
  owneremail: 'ownerEmail', 'е-пошта': 'ownerEmail', 'епошта': 'ownerEmail',
  ownerphone: 'ownerPhone', 'телефон': 'ownerPhone',
  openingbalance: 'openingBalance', 'почетно салдо': 'openingBalance',
};

const KINDS: Record<string, UnitKind> = {
  apartment: 'apartment', 'стан': 'apartment',
  commercial: 'commercial', 'деловен': 'commercial', 'деловен простор': 'commercial',
  parking: 'parking', 'паркинг': 'parking',
  storage: 'storage', 'подрум': 'storage', 'остава': 'storage',
  other: 'other', 'друго': 'other',
};

const EMAIL = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
const norm = (s: string): string => s.trim().toLowerCase().replace(/\s+/g, ' ');

/** "54,5" or "54.5" → 54.5; anything else → null. */
function parseDecimal(raw: string): number | null {
  const s = raw.replace(/\s/g, '');
  if (!/^-?\d+([.,]\d+)?$/.test(s)) return null;
  return Number(s.replace(',', '.'));
}

/** Parses the fixed units/owners template. Never throws: bad rows become errors and are skipped. */
export function parseUnitImport(text: string): UnitImportResult {
  const rows: UnitImportRow[] = [];
  const errors: UnitImportError[] = [];
  const lines = text.replace(/^﻿/, '').split(/\r?\n/);
  const headerIdx = lines.findIndex((l) => l.trim() !== '');
  if (headerIdx === -1) return { rows, errors: [{ line: 1, message: 'empty file' }] };

  const headerLine = lines[headerIdx]!;
  const delim = headerLine.split(';').length >= headerLine.split(',').length ? ';' : ',';
  const cols = splitCsvLine(headerLine, delim).map((c) => HEADERS[norm(c)] ?? null);
  const at = (f: Field): number => cols.indexOf(f);
  for (const required of ['label', 'kind'] as const) {
    if (at(required) === -1) errors.push({ line: headerIdx + 1, message: `missing required column: ${required}` });
  }
  if (errors.length > 0) return { rows, errors };

  const seen = new Set<string>();
  for (let i = headerIdx + 1; i < lines.length; i++) {
    const raw = lines[i]!;
    if (raw.trim() === '') continue;
    const line = i + 1;
    const cells = splitCsvLine(raw, delim);
    const cell = (f: Field): string => { const j = at(f); return j === -1 ? '' : (cells[j] ?? '').trim(); };

    const label = cell('label');
    if (!label) { errors.push({ line, message: 'label is required' }); continue; }
    if (seen.has(label)) { errors.push({ line, message: `duplicate label in file: ${label}` }); continue; }

    const kindRaw = cell('kind');
    const kind = KINDS[norm(kindRaw)];
    if (!kind) { errors.push({ line, message: `unknown kind: ${kindRaw || '(empty)'}` }); continue; }

    let areaM2: number | null = null;
    const areaRaw = cell('areaM2');
    if (areaRaw) {
      const v = parseDecimal(areaRaw);
      if (v === null || v <= 0 || v > 99_999_999) { errors.push({ line, message: `invalid areaM2: ${areaRaw}` }); continue; }
      areaM2 = v;
    }

    let ownershipShare: number | null = null;
    const shareRaw = cell('ownershipShare');
    if (shareRaw) {
      const v = parseDecimal(shareRaw);
      if (v === null || v < 0 || v > 1) { errors.push({ line, message: `invalid ownershipShare: ${shareRaw}` }); continue; }
      ownershipShare = v;
    }

    const email = cell('ownerEmail');
    if (email && !EMAIL.test(email)) { errors.push({ line, message: `invalid ownerEmail: ${email}` }); continue; }
    const ownerFirstName = cell('ownerFirstName');
    const ownerLastName = cell('ownerLastName');
    const ownerPhone = cell('ownerPhone');
    if (!ownerLastName && (ownerFirstName || email || ownerPhone)) {
      errors.push({ line, message: 'ownerLastName is required when any other owner column is filled' });
      continue;
    }

    let openingBalanceMinor = 0;
    const balanceRaw = cell('openingBalance');
    if (balanceRaw) {
      try {
        openingBalanceMinor = mkPack.parseAmountToMinor(balanceRaw);
      } catch {
        errors.push({ line, message: `invalid openingBalance: ${balanceRaw}` });
        continue;
      }
    }

    seen.add(label);
    rows.push({
      line, label, floor: cell('floor') || null, kind, areaM2, ownershipShare,
      ownerFirstName: ownerFirstName || null, ownerLastName: ownerLastName || null,
      ownerEmail: email ? email.toLowerCase() : null, ownerPhone: ownerPhone || null, openingBalanceMinor,
    });
  }
  return { rows, errors };
}

/**
 * Validates references, rejects a duplicate label and inserts the row. Runs inside the caller's
 * transaction and writes no audit row: `createUnit` and the CSV import add their own.
 */
export async function insertUnit(tx: Db, ctx: TenantContext, buildingId: string, input: UnitCreate): Promise<Row> {
  await validateRefs(tx, ctx, buildingId, input);
  const dup = await tx.query.units.findFirst({ where: and(eq(U.buildingId, buildingId), eq(U.label, input.label)), columns: { id: true } });
  if (dup) throw conflict('label_taken', `Unit ${input.label} already exists in this building`);
  try {
    const [row] = await tx.insert(U).values({ ...stripUndefined(toRow(input)), tenantId: ctx.tenantId, buildingId, label: input.label, kind: input.kind }).returning();
    return row!;
  } catch (err) {
    if (isUniqueViolation(err)) throw conflict('label_taken', `Unit ${input.label} already exists in this building`);
    throw err;
  }
}

export async function createUnit(db: Db, ctx: TenantContext, buildingId: string, input: UnitCreate) {
  return db.transaction(async (tx) => {
    await getBuilding(tx, ctx, buildingId);
    const row = await insertUnit(tx, ctx, buildingId, input);
    await writeAudit(tx, ctx, { action: 'unit.create', entityType: 'unit', entityId: row.id, after: row });
    return toOut(row, await ownerOf(tx, ctx, row.ownerContactId));
  });
}

/** One key per distinct owner in the file: email when present, else the exact name pair. */
function ownerKey(r: UnitImportRow): string | null {
  if (!r.ownerLastName) return null;
  return r.ownerEmail ? `e:${r.ownerEmail}` : `n:${(r.ownerFirstName ?? '').toLowerCase()}|${r.ownerLastName.toLowerCase()}`;

/** Labels of the file that already exist in the building. */
async function existingLabels(db: Db, ctx: TenantContext, buildingId: string, rows: UnitImportRow[]): Promise<string[]> {
  const labels = [...new Set(rows.map((r) => r.label))];
  if (labels.length === 0) return [];

    .where(and(eq(U.tenantId, ctx.tenantId), eq(U.buildingId, buildingId), inArray(U.label, labels)));
  return found.map((f) => f.label);
}

/**
 * Resolves every distinct owner of `rows` to a contact id: by lower(email) inside the tenant, else by
 * the exact first+last name inside the tenant, else created (only when `create` is set).
 */
async function resolveOwners(db: Db, ctx: TenantContext, rows: UnitImportRow[], create: boolean) {
  const byKey = new Map<string, UnitImportRow>();
  for (const r of rows) {
    const k = ownerKey(r);
    if (k && !byKey.has(k)) byKey.set(k, r);
  }
  const ids = new Map<string, string>();
  let existingContacts = 0;
  let newContacts = 0;
  for (const [k, r] of byKey) {
    const [match] = r.ownerEmail
      ? await db.select({ id: C.id }).from(C).where(and(eq(C.tenantId, ctx.tenantId), sql`lower(${C.email}) = ${r.ownerEmail}`)).limit(1)
      : await db.select({ id: C.id }).from(C).where(and(eq(C.tenantId, ctx.tenantId), eq(C.firstName, r.ownerFirstName ?? ''), eq(C.lastName, r.ownerLastName!))).limit(1);
    if (match) { ids.set(k, match.id); existingContacts++; continue; }
    newContacts++;
    if (!create) continue;
    const [row] = await db.insert(C).values({
      tenantId: ctx.tenantId, kind: 'person', firstName: r.ownerFirstName ?? '', lastName: r.ownerLastName!,
      email: r.ownerEmail, phone: r.ownerPhone,
    }).returning({ id: C.id });
    ids.set(k, row!.id);
  }
  return { ids, existingContacts, newContacts };
}

export async function importUnits(db: Db, ctx: TenantContext, buildingId: string, body: ImportUnitsBody) {
  const { rows, errors } = parseUnitImport(body.content);

  if (body.dryRun) {
    await getBuilding(db, ctx, buildingId);
    const conflicts = await existingLabels(db, ctx, buildingId, rows);
    const importable = rows.filter((r) => !conflicts.includes(r.label));
    const owners = await resolveOwners(db, ctx, importable, false);
    return {
      dryRun: true, rows, errors, conflicts,
      counts: {
        units: importable.length, newContacts: owners.newContacts, existingContacts: owners.existingContacts,
        openingBalances: importable.filter((r) => r.openingBalanceMinor !== 0 && ownerKey(r)).length,
        conflicts: conflicts.length,
      },
    };
  }

  return db.transaction(async (tx) => {
    await getBuilding(tx, ctx, buildingId);
    const conflicts = await existingLabels(tx, ctx, buildingId, rows);
    if (conflicts.length > 0 && body.mode === 'fail') {
      throw new AppError(409, 'label_conflict', 'Some unit labels already exist in this building', { labels: conflicts });
    }
    const importable = rows.filter((r) => !conflicts.includes(r.label));
    const withBalance = importable.filter((r) => r.openingBalanceMinor !== 0 && ownerKey(r));
    if (withBalance.length > 0 && (await hasPublishedPeriod(tx, ctx, buildingId))) {
      throw conflict('period_published', 'This building already has a published period; book opening balances from the Opening balances tab with force');
    }
    const owners = await resolveOwners(tx, ctx, importable, true);
    for (const r of importable) {
      const k = ownerKey(r);
      await insertUnit(tx, ctx, buildingId, {
        label: r.label, kind: r.kind,
        ...(r.floor !== null ? { floor: r.floor } : {}),
        ...(r.areaM2 !== null ? { areaM2: r.areaM2 } : {}),
        ...(r.ownershipShare !== null ? { ownershipShare: r.ownershipShare } : {}),
        ...(k ? { ownerContactId: owners.ids.get(k)! } : {}),
      });
    }
    const postings = withBalance.length > 0
      ? await insertOpeningBalances(tx, ctx, buildingId, withBalance.map((r) => ({
          contactId: owners.ids.get(ownerKey(r)!)!, fund: 'regular' as const, amountMinor: r.openingBalanceMinor, note: `import: ${r.label}`,
        })))
      : [];
    const counts = {
      units: importable.length, newContacts: owners.newContacts, existingContacts: owners.existingContacts,
      openingBalances: postings.length, conflicts: conflicts.length,
    };
    await writeAudit(tx, ctx, {
      action: 'import.units', entityType: 'building', entityId: buildingId,
      after: { counts, mode: body.mode, conflicts, errorCount: errors.length },
    });
    return { dryRun: false, rows: importable, errors, counts, conflicts };
  });
}

async function load() { rows.value = (await api.get<{ rows: User[] }>('/api/users')).rows; }
onMounted(async () => { try { await load(); } catch { error.value = t('app.error'); } });

function fail(e: unknown) {
  const code = (e as { code?: string }).code;
  error.value = code === 'email_taken' ? t('users.errors.email_taken')
    : code === 'last_owner' ? t('users.errors.last_owner')
    : code === 'forbidden' ? t('users.errors.forbidden')
    : code === 'validation' ? t('auth.errors.validation')
    : t('app.error');
}

async function create() {
  busy.value = true; error.value = ''; copied.value = false;
  try {
    const res = await api.post<CreatedUser>('/api/users', { email: form.value.email, firstName: form.value.firstName, lastName: form.value.lastName, role: form.value.role });
    temp.value = { email: res.user.email, password: res.temporaryPassword };
    open.value = false;
    form.value = { email: '', firstName: '', lastName: '', role: 'accountant' };
    await load();
  } catch (e) { fail(e); } finally { busy.value = false; }
}

async function toggle(u: User) {
  error.value = '';
  try { await api.patch(`/api/users/${u.id}`, { isActive: !u.isActive }); await load(); } catch (e) { fail(e); }
}

async function reset(u: User) {
  error.value = ''; copied.value = false;
  try {
    const res = await api.post<CreatedUser>(`/api/users/${u.id}/reset-password`, {});
    temp.value = { email: res.user.email, password: res.temporaryPassword };
  } catch (e) { fail(e); }
}

  if (!temp.value) return;
  try { await navigator.clipboard?.writeText(temp.value.password); copied.value = true; } catch { copied.value = false; }
}

  // `wildcard: false`: no catch-all GET route, so unknown paths reach the not-found handler below
  // and only that handler decides between the SPA shell and the JSON envelope.
  if (opts.config.serveWeb) await app.register(fastifyStatic, { root: opts.config.webDist, wildcard: false });

  app.setNotFoundHandler((req, reply) => {
    if (opts.config.serveWeb && req.method === 'GET' && !req.url.startsWith('/api')) return reply.sendFile('index.html');
    return reply.status(404).send({ error: { code: 'not_found', message: `Route ${req.method} ${req.url} not found` } });
  });

`docs/DEPLOY.md`:

```md
# Deploying domar

One server, three containers: `db` (Postgres 16), `api` (Fastify + the built web app) and `caddy`
(automatic HTTPS). Everything is driven by `docker-compose.prod.yml` and one `.env` file.

## Prerequisites

- A host with Docker and the compose plugin, ports 80 and 443 free.
- A DNS A record pointing your domain at the host — Caddy issues the certificate on first start.

## First deploy

    git clone <repo> /srv/domar && cd /srv/domar
    cp .env.example .env
    # set DOMAIN, POSTGRES_PASSWORD; leave SERVE_WEB/API_HOST to the image defaults
    docker compose -f docker-compose.prod.yml up -d --build

The API container runs `pnpm --filter @domar/db migrate` on every start (`scripts/docker-entrypoint.sh`)
and only then starts serving, so a failed migration keeps the old container's traffic off.
Open `https://$DOMAIN`, register the first organization — its first user is the `owner` who can then
create the rest of the staff from Settings → Users.

## Updating

    cd /srv/domar && git pull
    docker compose -f docker-compose.prod.yml up -d --build api

## Why the image runs `tsx`

`@domar/db` and `@domar/domain` are workspace packages whose `exports` point at TypeScript sources, so
the dev, test and production paths all load the same files. A `tsc`-emitted `apps/api/dist` would still
import `@domar/db` and hand Node a `.ts` file, and `pnpm deploy` would copy those packages into
`node_modules` where that resolution breaks. The image therefore keeps the workspace layout and runs
`pnpm --filter @domar/api start` (`tsx src/index.ts`), exactly like `pnpm dev`. `pnpm --filter @domar/api build`
(`tsc -p tsconfig.build.json`) runs during the image build purely as the type gate.

## PDFs

The base image is `mcr.microsoft.com/playwright:v1.63.0-noble`, matching the pinned `playwright-core`,
and the container sets `PDF_BROWSER_CHANNEL=chromium` so invoice PDFs use the browser that ships in it.
Bump the tag and `playwright-core` together.

## Backups

`scripts/backup.sh` writes `backups/domar-YYYY-MM-DD-HHMM.sql.gz` and keeps the newest 14. From cron:

    15 2 * * * cd /srv/domar && ./scripts/backup.sh >> /var/log/domar-backup.log 2>&1

Restore into a running stack:

    gunzip -c backups/domar-2026-10-01-0215.sql.gz | docker compose -f docker-compose.prod.yml exec -T db psql -U domar domar

## Environment

Every variable is documented in `.env.example`. In production the session cookie is `Secure` because
`NODE_ENV=production` (`isProduction`), and `TRUST_PROXY=1` makes rate limiting see the client IP that
Caddy forwards.
